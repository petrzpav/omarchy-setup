# Keybindings cheat sheet

All bindings, searchable: **Super + K**.

## Added by this setup

| Keys | What |
|---|---|
| Ctrl + Alt + R | Start/stop screen recording of the focused monitor with mic (crash-safe MKV in ~/Videos) |
| Ctrl + Alt + P | Pause/resume the recording (the bar icon shows the state) |
| Super + Shift + H | Herdr terminal |

## Omarchy essentials

| Keys | What |
|---|---|
| Super + Space | Omarchy menu (apps, settings, everything) |
| Super + Alt + Space | Apps menu |
| Super + Return | Terminal |
| Super + Shift + B | Browser |
| Super + W | Close window |
| Super + T | Toggle floating/tiling |
| Super + O | Pop window out (float and pin) |
| Super + 1…9 | Switch workspace (add Shift to move the window there) |
| Print | Screenshot |
| Super + Ctrl + C | Capture menu (screenshots, recordings, OCR) |
| Super + Shift + Ctrl + Space | Theme menu |
| Super + Escape | System menu (lock, suspend, restart) |
| Super + Ctrl + L | Lock |

## Bar

Bottom of the screen. The center shows the workspace pager and status icons
(dictation, recording, reminders, night light, stay-awake) next to the clock.
The wallpaper changes every 3 hours (wallswap; click its icon for options).
